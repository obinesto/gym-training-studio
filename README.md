# Gym Training Studio 🏋️‍♀️

A modern, fully responsive, and visually appealing landing page template for a gym or fitness studio. This project is built with pure HTML, CSS, and JavaScript, making it lightweight, fast, and easy to customize.

**Live Demo:** [**https://gym-training-studio.vercel.app/**](https://gym-training-studio.vercel.app/)



---

## ✨ Features

This template is packed with all the essential sections a fitness website needs:

*   **🏠 Home:** A stunning hero section with a clear call-to-action to grab visitors' attention.
*   **💪 Programs:** Showcase your fitness programs (e.g., Strength Training, Cardio, Fat Burning) in a clean, card-based layout.
*   **💲 Pricing:** Display your membership plans with detailed features and a "Join Now" button for each tier.
*   **👥 About Us:** Share your story and what makes your studio unique.
*   **📱 Fully Responsive:** Looks great on all devices, from mobile phones to desktop computers.
*   **🚀 Lightweight & Fast:** Built with standard web technologies for optimal performance.
*   **🎨 Easy to Customize:** Clean and well-structured code makes it simple to change text, images, and styles to fit your brand.
*   **SMOOTH SCROLLING:** for better user experience.

---

## 🛠️ Technologies Used

*   **HTML5:** For the core structure and content.
*   **CSS3:** For styling, layout, and responsiveness.
*   **JavaScript:** For dynamic features like the mobile navigation menu and smooth scrolling.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You just need a modern web browser. No complex dependencies or build tools are required!

### Installation

1.  Clone the repository:
    ```sh
    git clone https://github.com/obinesto/gym-training-studio.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd gym-training-studio
    ```
3.  Open the `index.html` file in your browser to view the website.
